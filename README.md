# cracklepop

Snapcast control client and player for Android TV

[![Github Releases](https://img.shields.io/github/release/slatkin/cracklepop.svg)](https://github.com/slatkin/cracklepop/releases)

cracklepop is using the [Snapcast JSON-RPC API](https://github.com/badaix/snapcast/blob/master/doc/json_rpc_api/v2_0_0.md) to control [Snapcast](https://github.com/badaix/snapcast) and bundles native Android ARM and X86 Snapclients for audio playback

![Snapcast for Android](https://raw.githubusercontent.com/badaix/snapcast/master/doc/snapcast_android_scaled.png)

You can find the current APK for your device on the [releases-page](https://github.com/slatkin/cracklepop/releases) and on [Google Play](https://play.google.com/store/apps/details?id=de.badaix.snapcast).
